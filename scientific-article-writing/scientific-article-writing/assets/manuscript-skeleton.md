# Manuscript skeleton

One row per planned paragraph. Fill the `Evidence` column with a locator into the author's materials, or label the row `structural_transition` or `author_confirmation`. Allowed status values: `planned`, `drafted`, `blocked`, `audited`.

The default rows below encode the section moves in `references/sections.md`. Delete, merge, or reorder rows to match the venue and the storyboard; never fill a row with content the materials lack.

## Introduction

| Order | Paragraph | Reader question | Information function | Evidence | Boundary or risk | Status |
|---:|---|---|---|---|---|---|
| 1 | Territory | What is this about and why does it matter? | Establish the phenomenon at the readers' shared level | | Avoid universal claims | planned |
| 2 | Known | What do we already know? | Synthesize prior work by idea | | Citations attached to propositions | planned |
| 3 | Unresolved | What is contested or untested? | State competing accounts or the limit of prior methods | | Do not invent a debate | planned |
| 4 | Gap and stakes | What is unknown and what goes wrong if it stays unknown? | Define the gap and its consequence | | No unverified "no study has" | planned |
| 5 | Present study | What did this study do and predict? | Aim, approach, explicit predictions | | Promise only what Results delivers | planned |

| 3 | Materials | What was presented or applied? | Stimuli, tasks, devices | | | planned |
| 4 | Procedure | In what order, with what timing? | Chronological sessions and trials | | | planned |
| 5 | Acquisition | With what equipment and settings? | Parameters, targeting, controls | | | planned |
| 6 | Preprocessing | How was signal cleaned? | Ordered steps, software versions, rejection counts | | | planned |
| 7 | Analysis | How were outcomes computed and tested? | Measures, models, tests, corrections, exploratory labels | | Planned vs completed | planned |
| 8 | Availability | Where are data and code? | Repository locations | | Never invented | planned |

## Results

One block per storyboard row. Header states the claim.

| Order | Subsection (claim) | Beat | Information function | Evidence | Boundary or risk | Status |
|---:|---|---|---|---|---|---|
| 1 | | Aim | Which question this analysis answers | | | planned |
| 1 | | Approach | How, briefly, pointing to Methods | | | planned |
| 1 | | Result | Finding with statistic, uncertainty, figure callout, null results | | Direction and comparator exact | planned |
| 1 | | Takeaway | One bounded sentence | | No mechanism, no literature | planned |

## Discussion

| Order | Paragraph | Reader question | Information function | Evidence | Boundary or risk | Status |
|---:|---|---|---|---|---|---|
| 1 | Findings summary | What did you find? | Restate main findings at Results strength | | No stronger verbs than Results | planned |
| 2 | Prior work | How does this relate to what was known? | Replicated / extended / contradicted with specific differences | | Author-supplied literature only | planned |
| 3 | Interpretation | What does the pattern support? | Author's account at ladder strength | | author_judgment required | planned |
| 4 | Alternatives | What else could explain it? | Named alternatives and what argues against them | | author_judgment required | planned |
| 5 | Limitations | What bounds the claims? | Limitation -> consequence -> mitigation -> future | | Documented limitations only | planned |
| 6 | Implications | Why should the field care? | Theory, method, or practice at supported strength | | Implication vs recommendation | planned |
| 7 | Conclusion | What is the answer? | Bounded answer and contribution | | No new claims | planned |

## Front matter, written last

| Order | Element | Reader question | Information function | Evidence | Boundary or risk | Status |
|---:|---|---|---|---|---|---|
| 1 | Abstract | Should I read this? | Context -> gap -> done here -> findings -> conclusion -> implication | | No claim absent from paper | planned |
| 2 | Highlights or blurb | What are the findings in one glance? | One finding per bullet | | Venue limits | planned |
| 3 | Title | What is promised? | Fewest words, finding or question, design when it changes inference | | Title-paper promise check | planned |
